# Mavics Resort Booking System

A full booking and reservation platform built for Mavics Resort, a commissioned project delivered to a real small business client through Pantheon Hub.

## Features

**Customer side**
- Browse venues, rooms, and amenities
- Place and manage bookings
- View billing and choose payment methods
- Message resort staff directly
- View booking history
- Browse photo gallery

**Admin side**
- Manage bookings and export booking data
- Track and manage payments
- View reports and analytics
- Manage venues and gallery content
- Manage site content (about, footer, contact) through a built-in CMS
- Manage user accounts

## Tech Stack

- PHP
- MySQL
- HTML, CSS, JavaScript
- XAMPP (Apache, MySQL)

## Getting Started

1. Clone this repo into your XAMPP `htdocs` folder.
2. Import `mavics_resort.sql` into MySQL through phpMyAdmin.
3. Update database credentials in `customer/config/database.php` (and the equivalent admin config) if your local setup differs from the XAMPP default.
4. Start Apache and MySQL in XAMPP.
5. Visit `http://localhost/<repo-name>/customer` for the customer-facing site, and `/admin` for the admin panel.
